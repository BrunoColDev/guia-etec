# Guia ETEC

O Guia ETEC é uma plataforma web desenvolvida como Trabalho de Conclusão de Curso (TCC) durante minha formação técnica na ETEC.

## Funcionalidades

- Cadastro e login de usuários
- Área do aluno
- Conteúdos e materiais de estudo
- Simulados
- Calendário
- Acompanhamento de atividades

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Estrutura do projeto

- assets/ - arquivos de estilo, scripts, imagens e outros recursos
- backend/ - autenticação, conexão com banco e funcionalidades do servidor
- banco/ - estrutura do banco de dados
- pages/ - páginas da plataforma
- inicio.php - página inicial

## Objetivo

O projeto surgiu a partir da dificuldade de estudantes em encontrar informações organizadas sobre o processo de ingresso nas ETECs. A proposta foi reunir essas informações em uma única plataforma de forma simples e acessível.

## Sobre o projeto

Este projeto foi desenvolvido para fins acadêmicos como TCC e representa uma experiência prática com desenvolvimento web, integração com banco de dados e criação de funcionalidades de autenticação.

O projeto ainda possui alguns pontos que podem ser melhorados, já que representa o que desenvolvemos e aprendemos durante o período do TCC.
